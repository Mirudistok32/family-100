# Семья на 100 лет

Сайт-курс на 7 дней: зачем нужна семья, как её создать и как растить её силу и силу каждого в ней.
Для автора, школьников 14–17 лет и пар. В конце остаются чек-листы, памятки и своя семейная конституция.

## Как открыть

```bash
npm install
npm run dev        # сервер разработки: http://localhost:4321/family-100/
npm run build      # сборка в dist/
npm run preview    # посмотреть сборку
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run check` | Быстрый гейт: типы, линтер, формат, юнит-тесты |
| `npm run check:full` | `check` + сборка + e2e |
| `npm run lighthouse` | Lighthouse по собранному сайту, отчёты в `.lighthouse/` |
| `npm run weight` | Вес сборки по типам файлов и страницам |
| `npm run plan` | Прогресс плана |

## Стек

Astro и TypeScript без фреймворка интерфейса. Записи пользователя лежат только в `localStorage` этого
браузера, бэкенда нет.

## Где что лежит

- `src/pages` — маршруты, `src/layouts` — шаблоны, `src/domain` — чистая логика.
- `tests/unit` — Vitest, `tests/e2e` — Playwright с axe.
- `docs/` — архитектура, решения, правила текста, источники.
- `PLAN.md`, `PLAN-LOG.md` — план работ и журнал.

## Ограничения

- Открытие двойным кликом с диска не поддерживается: курс живёт по ссылке.
- Публикация на GitHub Pages — только по отдельной просьбе.
