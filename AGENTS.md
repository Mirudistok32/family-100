# Семья на 100 лет

Сайт-курс на 7 дней о том, зачем нужна семья и как её строить, для автора, школьников 14–17 лет и
пар. Интерфейс, документация и ответы — по-русски.

Общие принципы и имена команд — `../agent-base/docs/` (principles, conventions, learning, local-data).
Здесь — только то, что отличает этот проект.

## Стек и запуск

- Astro + TypeScript без фреймворка интерфейса; данные пользователя — `localStorage` (`family100:*`),
  бэкенда нет.
- Открыть: `npm run dev`. Публикация: GitHub Pages, только по отдельной просьбе.

## Проверки

- `npm run check` — быстрый гейт перед коммитом; `npm run check:full` — + сборка и e2e.
- Визуально: `/shots` (390/1280, тёмная/светлая).

## План

- Файл: `PLAN.md`, журнал: `PLAN-LOG.md`. Пункт — `/next-task [N.M]`, прогресс — `/plan-status`.
- Гейт пункта: `npm run check:full`.
- Коммиты: по пункту — conventional commits по-русски, заголовок ≤ 72 символов. Без трейлеров Claude.
- Ветка: `master`.

## Позиция курса

- Курс о союзе мужчины и женщины и их детях. Это авторская ценность, а не научный вывод. Других не
  критикуем: геев и лесбиянок в курсе нет ни как темы, ни как объекта нападок.
- Неполные и приёмные семьи не обесцениваем. Мысль для ребёнка из такой семьи: «свою будущую семью
  строишь ты».
- Никто не обязан оставаться рядом с насилием и разрушением ради звания семьи. Можно отдалиться и стать
  первым поколением по своим правилам. Сохранить семью любой ценой курс не учит.

## Нельзя

- Менять и удалять ключи `localStorage`, id дней, частей и пунктов чек-листов без миграции.
- Глушить правила линтера, удалять тесты, снижать пороги ради зелёного гейта.
- Отправлять записи пользователя куда-либо, добавлять аналитику и внешние запросы на страницах с записями.
- Публиковать факт без источника. Выдавать собирательных героев за реальных людей.
- Описывать способы самоповреждения, вещества и дозы. Ставить диагнозы. Советовать разбираться с
  обидчиком один на один.
- Публиковать день 5 без проверки специалистом (пункт 5.4 плана).
