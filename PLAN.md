# План: курс «Семья на 100 лет»

Сайт-курс на 7 дней для портфолио, автора и тех, кто не видел хорошего примера семьи: зачем она
нужна, как её создать и как растить её силу и силу каждого в ней. Основа — «Family Wealth»
Джеймса Хьюза, дополняют другие книги, история, исследования, философия и этика. В конце у
человека остаются чек-листы, памятки и своя семейная конституция.

```
/                 главная: о чём курс, где остановились, помощь
/day/1 … /day/7   уроки; день 5 разбит на четыре части
/memos            все памятки для печати
/ethics           вопросы этики и философы по дням
/my-family        мои записи, семейная конституция, копия и удаление данных
/help             телефоны и службы помощи, ссылка на неё есть на каждой странице
/finish           конец курса: что сделано и что вернуть в календарь
/about            позиция автора, источники, приватность
```

Устройство урока: вопрос → история → пример из жизни → суть → вопрос этики → задание →
чек-лист «Мне 14–17» и чек-лист «Мы уже пара» → памятка → источники. На день — 20–30 минут.

## Как работаем

- Идём по порядку: этап → пункт. Запуск — `/next-task` или `/next-task 1.3`, прогресс —
  `/plan-status`. Готовый пункт сворачивается в одну строку, подробности — в `PLAN-LOG.md`.
- Гейт пункта: `npm run check:full` зелёный. Чиним причину, а не проверку.
- Коммиты: один пункт = один коммит, conventional commits по-русски. Пуш и публикация — только по
  отдельной просьбе.
- Никогда не ломаем: ключи `family100:*`, id дней, частей, пунктов чек-листов и адреса страниц.
- **Режим до отмены (просьба пользователя 31.10.2026):** идём по всем пунктам подряд, без вопросов. Что требует решения пользователя,
  записываем в `docs/open-questions.md` с принятым умолчанием и спрашиваем, когда он остановит работу. Пункты «Делает пользователь»
  не выполняем и идём дальше: день 2 пишем, не дожидаясь ответа в 2.2. Публикации и пуша по-прежнему нет.
- Пункт закрываем только после зелёного гейта: `done` идёт через `&&` после `check:full`, а не через `;`.
- Вместе с кодом обновляем: `docs/editorial.md`, `docs/design-system.md`, `docs/architecture.md`,
  `docs/sources.md`, `docs/decisions.md`, README.

## Решения пользователя

- Название — «Семья на 100 лет». Стек — Astro. Дизайн — «Семейный альбом»: тёплая бумага, крупный
  шрифт с засечками, карточки и записи от руки. Примеры из жизни — сквозные собирательные герои,
  это указано на сайте. Коммиты — по пункту.
- Курс о союзе мужчины и женщины и их детях. Это авторская ценность, а не научный вывод. Других
  не критикуем: геев и лесбиянок в курсе нет ни как темы, ни как объекта нападок.
- В курсе есть алкоголь, наркомания, абьюз и насилие в семье. Позиция автора: никто не обязан
  оставаться рядом с насилием и разрушением ради звания семьи. Можно отдалиться и стать первым
  поколением по своим правилам.

## Решения по умолчанию

Выбраны агентом, чтобы работа не стояла. Пользователь может передумать.

- Адрес проекта — `family-100`, публикация — GitHub Pages. Открытие двойным кликом с диска не цель:
  в Astro это отдельная сборка, а курс живёт по ссылке.
- Фреймворк интерфейса не подключаем: контент в Markdown и коллекциях Astro, чек-листы и записи —
  небольшие скрипты на TypeScript. Весь текст виден без JavaScript.
- Без аналитики, аккаунтов и внешних запросов с записями пользователя. Шрифты — свои файлы.
- Порядок дней рекомендованный, но ничего не заперто. Стриков и наказаний нет.
- День 5 пропустить можно, переход на него не обязателен для следующих дней.
- Для школьника отдалиться сейчас часто значит иное, чем для взрослого: безопасный взрослый,
  службы помощи, внутренние границы и план самостоятельности. Взрослому доступны границы, редкие
  контакты или полный разрыв.

## Открытые вопросы (не блокируют)

- Возрастная маркировка: решено 01.11.2026 в 5.3, знак 16+. Сайт не СМИ, знак добровольный.

- Книга Хьюза: номера глав указываем, только если сверены с изданием; иначе ссылка на книгу целиком.
