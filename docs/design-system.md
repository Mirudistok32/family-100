# Дизайн-система «Семейный альбом»

Выбор пользователя: тёплая бумага, крупный шрифт с засечками, карточки и записи от руки. Настроение спокойное, такое, чтобы
выдержать и тяжёлые темы. Тема следует настройке системы, отдельного переключателя нет: меньше кода и ключей в хранилище.

## Шрифты

| Шрифт | Зачем | Файлы | Лицензия |
| --- | --- | --- | --- |
| Literata | Весь текст и заголовки: книжный, с хорошей кириллицей | `@fontsource-variable/literata`, кириллица и латиница, обычный и курсив | OFL 1.1 |
| Caveat | Только короткие подписи от руки, класс `.hand`, не длинный текст | `@fontsource-variable/caveat`, кириллица и латиница | OFL 1.1 |

Шрифты лежат на нашем сайте, внешних запросов нет. Основной файл кириллицы подгружается заранее (`preload`).

## Цвета

Токены в `src/styles/tokens.css`, менять только там. Контраст проверяет `npm run contrast`: текст 4,5:1, элементы интерфейса 3:1.

| Токен | Светлая | Тёмная | Где |
| --- | --- | --- | --- |
| `--paper` | `#f5eddc` | `#1e1812` | Фон страницы |
| `--paper-raised` | `#fffaf0` | `#2a2219` | Панели |
| `--photo-edge` | `#fffdf7` | `#352b20` | Фотокарточка |
| `--note` | `#fbf0c4` | `#3a3120` | Записка |
| `--ink` | `#2a1f16` | `#f3ead9` | Основной текст |
| `--ink-soft` | `#5c4a39` | `#cdbfa9` | Подписи |
| `--accent` | `#8c3a22` | `#e9a784` | Ссылки, кнопки |
| `--green` | `#2c5a4c` | `#8fcfb7` | Спокойные блоки |
| `--danger` | `#981b1b` | `#ff9d8f` | Помощь на тяжёлых страницах |

## Текст

- База 18 px, межстрочный 1,65, ширина колонки до 42rem.
- Заголовки плавно растут от телефона к компьютеру, задаются через `clamp`.
- Мелкий текст не меньше 16 px.

## Блоки

| Класс | Что это | Где используется |
| --- | --- | --- |
| `.photo-card` | Фотокарточка: рамка и уголки | «История» — реальные люди |
| `.note` | Записка на полях | «Пример из жизни» — придуманные герои |
| `.callout` | Важная мысль | Суть урока |
| `.callout--calm` | Спокойный блок | Памятка |
| `.callout--danger` | Блок помощи | Тяжёлые страницы, не для украшения |
| `.hand` | Подпись от руки | Заголовок блока, короткие метки |
| `.btn`, `.btn--ghost` | Кнопки | Минимальная высота 44 px |

«История» и «Пример из жизни» различаются внешне намеренно: читатель должен видеть, где реальные люди, а где герои.

## Доступность и движение

- Фокус всегда виден: контур 3 px цветом `--accent`.
- Размер цели не меньше 44 px.
- `prefers-reduced-motion` отключает анимацию и переходы.
- Цвет не единственный носитель смысла: у блоков есть подписи.
