# Источники и проверка фактов

Единственная база фактов курса. В уроках используем только то, что здесь есть со статусом «проверено».
Проверка: 31.10.2026, книга Хьюза и её главы — 01.11.2026.

**Статусы:**

- **проверено** — подтверждено первоисточником или официальным источником;
- **проверено (вторично)** — подтверждено только пересказом: обзором, энциклопедией, статьёй. В тексте пишем с
  оговоркой: «по данным…», «как пересказывает…». Перед публикацией желательно сверить с книгой;
- **не подтвердилось** — в курсе не используем.
