# Принятые решения

Долгоживущие решения и отступления от плана. Одна строка — одно решение.

| Решение | Причина |
| --- | --- |
| **Astro, «Семейный альбом», сквозные герои, коммиты по пункту** (план) | Выбор пользователя |
| **`base: /family-100` задан сразу** (0.1) | Ссылки и e2e с первого дня проверяются в подпапке, как на GitHub Pages; в 5.5 правки `base` не потребуется, если имя репозитория останется тем же |
| **TypeScript 6.0, а не 7** (0.1) | `typescript-eslint` и `@astrojs/check` пока не поддерживают 7 |
| **Тема следует настройке системы, переключателя нет** (1.1) | Меньше кода и ключей в хранилище; WCAG переключатель не требует |
| **В JSON-LD поставщик — название курса, без имени автора** (1.3) | Имя автора на сайте выбирает пользователь |
| **Согласие на сохранение чувствительных записей — на каждое поле отдельно, импорт заменяет данные, а не объединяет** (1.5) | Общий переключатель легко включить и забыть; объединение двух копий ведёт к конфликтам |
| **Четыре капитала — рамка курса, а не формула Хьюза** (4.1) | В книге 2004 года названы человеческий, интеллектуальный и финансовый капитал, социальный добавляют более поздние пересказы. В текстах Хьюзу приписываем только то, что у него есть. |
| **«Аудит капиталов» хранится в записях заданий, а не в отдельном ключе** (4.2) | План требует, чтобы аудит попадал в копию данных. Запись `d6-means-task-audit` сама идёт в копию, импорт и «стереть всё»; новый ключ потребовал бы менять формат копии и версию. |
| **Аудит спрашивает баллы, а не суммы** (4.2) | Суммы на общем устройстве раскрыли бы положение семьи, а для шага они не нужны. |
| **Конституция не копирует записи дней 2 и 3, а показывает те же поля** (4.4) | Копия разошлась бы с записью, а согласие перестало бы что-либо значить. На `/my-family` такое поле стоит в конституции и убрано из списка заданий: два поля с одним id разошлись бы на странице. |
| **Страница `/my-family` печатает только лист конституции** (4.4) | Случайная печать всех личных записей опаснее, чем отсутствие такой возможности: бумагу не сотрёшь кнопкой. Для переноса записей есть копия данных. |
| **Лист длиннее двух страниц не запрещён, а предупреждается** (4.4) | Запись может быть длинной, а обрезать текст человека нельзя. Два листа — ориентир, поэтому только сообщение. |
| **`/ethics` собирается из разделов уроков, а не пишется отдельно** (4.5) | Отдельный текст разошёлся бы с уроками, а изложение мыслителей и так сверено в уроках. |
| **Экран завершения показывает только сделанное и сам не напоминает** (4.5) | Проценты и пропущенное превратили бы итог в оценку, а курс обещает обойтись без стриков. Напоминаний нет, потому что нет ни аккаунтов, ни рассылок: человек сам переносит дела в свой календарь. |
| **Имени автора на сайте и в JSON-LD нет** (5.3) | Решение пользователя: курс затрагивает личные темы, а добавить имя можно в любой момент. |
| **Курс — авторская книга: без законов, без внешней проверки перед публикацией** (01.11.2026) | Решение пользователя. Отдельной проверки юристом и специалистом нет |
| **Курс построен по оглавлению «Богатства семьи» Хьюза** (6.1) | Решение пользователя: «это наша основа». Формат 7 дней и адреса `/day/1–7` сохранены, дни о выборе супруга и о ссорах ушли, главы о трастах заменены тем, что подходит обычной семье. Варианты «старое начало» и «4 части вместо дней» пользователь отклонил |
| **Нет подростков, опасности, насилия, зависимостей, психологов, служб помощи** (6.1) | Решение пользователя: не заменять другими словами, а убрать совсем. Удалены день 5 с частями, «Быстрый выход», предупреждения, «Моя ситуация», `/help`, линия Лёши. Список запрещённых тем проверяет `findBannedTopic` на всех страницах |
| **Герои только взрослые, линия Лёши удалена** (6.1) | Решение пользователя. Катя, Миша и Тимур показаны такими, какими раньше были «через 12 лет» |
| **Знак 16+ остаётся без объяснения на `/about`** (6.1) | Пользователь выбрал знак 16+ раньше и не отменял его. Объяснение было о теме насилия и обращении к младшим, поэтому его больше нет |
| **Чек-листы теперь «Начинаю с себя» и «Делаем вместе», новые id `dN-self-*` и `dN-together-*`** (6.1) | Пункты прежней программы больше не существуют. Старые отметки убирает миграция, а старое значение `teen` в аудите и конституции читается как `self` (`docs/save-format.md`) |
| **Id записей не менялись, даже когда день в них устарел: `d7-task-mission` живёт в дне 2** (6.1) | Id — данные пользователя. Запись остаётся на месте и на новом дне показывается как есть |
| **Механизм согласия на сохранение оставлен** (6.1) | Это приватность личных записей, а не тема насилия |
| **Лента эпох и советы — новые разделы урока, а не новые дни** (7.1) | Просьба автора: расширить программу, добавить традиции и советы. Семь дней и адреса уже решены. В каждом дне было около 1400 слов при норме 2000–3000, запас есть |
| **В ленту добавлен XX век там, где есть источники** (7.1) | Автор назвал славян, Русь, империю и сейчас «например». Без XX века непонятно, откуда взялись ЗАГС и привычная свадьба. В днях 1, 2, 4, 6, 7 его нет: подтверждённых фактов к теме дня не нашлось |
| **Умыкание невест и другие запретные темы из истории не пишем** (7.1) | Запрет автора распространяется и на историю: «не переписываем другими словами, а убираем совсем». Цена — лента беднее настоящей истории, это записано в `docs/editorial.md` |
| **Новые пункты чек-листов только добавлены, старые id не менялись** (7.1) | У старых данных отметки сохраняются. День, отмеченный полностью, снова покажет два неотмеченных пункта: это честно, пункты новые |
