# Принятые решения

Долгоживущие решения и отступления от плана. Одна строка — одно решение.

| Решение | Причина |
| --- | --- |
| **Astro, «Семейный альбом», сквозные герои, коммиты по пункту** (план) | Выбор пользователя |
| **`base: /family-100` задан сразу** (0.1) | Ссылки и e2e с первого дня проверяются в подпапке, как на GitHub Pages; в 5.5 правки `base` не потребуется, если имя репозитория останется тем же |
| **TypeScript 6.0, а не 7** (0.1) | `typescript-eslint` и `@astrojs/check` пока не поддерживают 7 |
| **Тема следует настройке системы, переключателя нет** (1.1) | Меньше кода и ключей в хранилище; WCAG переключатель не требует |
| **Черновики собираются только в режиме `drafts`** (1.3) | Обычная сборка для публикации не может случайно выложить день 5 до проверки специалистом |
| **В JSON-LD поставщик — название курса, без имени автора** (1.3) | Имя автора на сайте выбирает пользователь |
| **Согласие на сохранение чувствительных записей — на каждое поле отдельно, импорт заменяет данные, а не объединяет** (1.5) | Общий переключатель легко включить и забыть; объединение двух копий ведёт к конфликтам, которые подросток не должен разбирать |
| **Контакт на `/help` только со страницы самой службы, и только если организации нет в реестре иноагентов** (1.7) | Неверный номер в тяжёлый момент опаснее его отсутствия. Что не подтвердилось, не публикуем, а записываем в `docs/sources.md` |
| **`/day/5/` до проверки специалистом отвечает страницей без текста дня, а не 404** (2.5) | План требует ссылку на день 5 из дня 4, а человек с тяжёлой темой не должен попасть на ошибку. На странице только причина и контакты помощи, текст дня не публикуется |
| **Признаки насилия — список без галочек, под чек-листами тяжёлых страниц предупреждение об общем устройстве** (3.2) | Отмеченный признак остался бы в `localStorage` и мог выдать подростка тому, кого он боится |
| **Ответы «Моей ситуации» не сохраняются совсем, а поля для записи под ней только по согласию** (3.3) | Ответ «дома бывает страшно» в `localStorage` мог бы выдать подростка, а при выбранной опасности инструмент не показывает лестницу и признаки перемен, сколько бы их ни было отмечено: безопасность важнее. Инструмент подсказывает, с чего начать, и не решает за человека |
| **«Мои правила» сохраняются только по согласию, хотя потом нужны конституции** (3.4) | Строка «в моём доме не бьют» на общем устройстве может выдать подростка. Безопасность важнее удобства: в конституцию правила попадают через обычную запись, если человек сам включил сохранение |
