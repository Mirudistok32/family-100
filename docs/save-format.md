# Формат данных пользователя

Всё хранится только в `localStorage` этого браузера. Ключи и формат постоянные: изменение только с миграцией и тестом на реальном старом примере.

## `family100:progress:v1`

```json
{
  "schemaVersion": 1,
  "checked": ["d1-self-1", "d1-together-2"],
  "last": { "id": "day-1", "title": "Богатство семьи и горизонт 100 лет", "path": "/family-100/day/1/" }
}
```

| Поле | Что это |
| --- | --- |
| `schemaVersion` | Версия формата |
| `checked` | Постоянные id отмеченных пунктов чек-листов |
| `last` | Последний открытый урок, необязательное поле |

Правила:

- Содержимое хранилища считается недоверенным: всё неверное отбрасывается при чтении, `last.path` принимается только как внутренний путь, название выводится только как текст.
- Ошибка записи не теряет отметку: она действует, пока открыта страница, и рядом появляется сообщение.
- Другая вкладка подхватывает изменения. При одновременной правке побеждает последняя запись.
- Дат и серий дней здесь нет намеренно: курс без стриков и наказаний.

## `family100:notes:v1`

```json
{
  "schemaVersion": 1,
  "fields": { "d1-task-circle": "Текст записи", "d1-task-hard": "Текст личной записи" },
  "keep": ["d1-task-hard"]
}
```

| Поле | Что это |
| --- | --- |
| `schemaVersion` | Версия формата |
| `fields` | Постоянный id поля задания → текст записи. Пустых записей нет. До 10 000 знаков на запись |
| `keep` | Поля с `sensitive: true`, для которых сохранение включено явно |

Правила:

- Текст поля с `sensitive: true` сохраняется, только если его id есть в `keep`. Выключение сохранения сразу стирает текст из хранилища.
- Записи с неизвестным id не удаляются: они могут принадлежать дню, которого нет в этой сборке.
- Другая вкладка подхватывает изменения, но не трогает поле в фокусе и несохраняемый ввод.

## Семейная конституция

Своего ключа и правки формата нет: части лежат в `family100:notes:v1` и сами идут в копию. Копий текста тоже нет: общая запись одна, поэтому выключение сохранения в любом месте убирает её отовсюду.

| Часть | Id записи | Чувствительная |
| --- | --- | --- |
| Миссия | `d7-task-mission`, общая с днём 2 | нет |
| Ценности | `constitution-values` | нет |
| Правила | `d5-first-generation-task-rules`, только в конституции | нет |
| Решения | `constitution-decisions` | нет |
| Деньги | `constitution-money` | нет |
| Что не повторяем | `constitution-not-repeat` | да |
| Традиции | `d7-task-tradition`, общая с днём 3 | нет |

Версия лежит в записи `constitution-version`: `self` или `couple`. Незнакомое значение и старое `teen` читаются как `self`.

Чувствительная часть без согласия живёт только в поле на странице. Пока страница открыта, она видна на листе и попадает на печать, но в хранилище её нет.

## Что не хранится

Ответы «Аудита капиталов» (день 4) лежат в записях под постоянным id `d6-means-task-audit`, значением служит строка JSON: `{"audience":"self","answers":{"self-save":1}}`. Ответ: 0 — пока нет, 1 — отчасти, 2 — да. Отдельного ключа и правки формата копии нет. При чтении незнакомые вопросы и значения отбрасываются (`src/domain/capital-audit.ts`). Id вопросов постоянные. Сумм и имён аудит не спрашивает.

## Миграция 6.1: программа по книге Хьюза

Ключи и `schemaVersion` не менялись. Срабатывает при чтении из хранилища и из файла копии. Тесты на настоящих старых примерах: `tests/unit/progress.test.ts`, `capital-audit.test.ts`, `constitution.test.ts`, `backup.test.ts`.

| Что было | Что стало |
| --- | --- |
| Отметки `d1-teen-1`, `d6-people-couple-2` и все пункты прежней программы | Убираются (`RETIRED_ITEM`): таких пунктов больше нет, и в итог они не идут |
| `last` с `day-5/abuse` или с названием прежнего дня | Убирается, пока не откроется новый урок: страницы больше нет или название устарело |
| Аудит: `audience: teen`, вопросы `teen-*` | Читаются как `self` и `self-*`, ответы сохраняются |
| Конституция: `constitution-version: teen` | Читается как `self` |
| Записи `d5-*`, `d2-task-*` и другие записи старых заданий | **Остаются в хранилище и в копии без изменений** и не показываются на страницах: их поля удалены. Стираются кнопкой «Стереть всё» |
| Записи `d7-task-*`, `d6-people-task-*`, `d6-means-task-*`, `d1-task-*`, `d5-first-generation-task-rules` | Те же id на новых днях, текст на месте |

## Файл копии

Копия — файл JSON `family-100-kopiya-ГГГГ-ММ-ДД.json`, его хранит сам пользователь. Записи в нём лежат открытым текстом.

```json
{
  "format": "family100-backup",
  "version": 1,
  "exportedAt": "2026-10-31T12:00:00.000Z",
  "progress": { "schemaVersion": 1, "checked": [] },
  "notes": { "schemaVersion": 1, "fields": {}, "keep": [] }
}
```

- Файл недоверенный: `progress` и `notes` проходят те же проверки, что и хранилище, а вывод на страницу идёт только через `textContent`. Предел размера — 1 МБ.
- Импорт заменяет данные, а не объединяет их, и только после предпросмотра и подтверждения. Текст чувствительных полей без `keep` при импорте отбрасывается.
- Файл новой версии не читается как старый: показываем сообщение, данные не меняем.
- «Стереть всё» удаляет `family100:progress:v1` и `family100:notes:v1` и очищает поля на странице.
