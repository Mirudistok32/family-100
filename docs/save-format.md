# Формат данных пользователя

Всё хранится только в `localStorage` этого браузера. Ключи и формат постоянные: изменение только с миграцией и тестом на реальном старом примере.

## `family100:progress:v1`

```json
{
  "schemaVersion": 1,
  "checked": ["d1-teen-1", "d1-couple-2"],
  "last": { "id": "day-1", "title": "Зачем нужна семья", "path": "/family-100/day/1/" }
}
```

| Поле | Что это |
| --- | --- |
| `schemaVersion` | Версия формата |
| `checked` | Постоянные id отмеченных пунктов чек-листов |
| `last` | Последний открытый урок, необязательное поле |

Правила:

- Содержимое хранилища считается недоверенным: всё неверное отбрасывается при чтении, `last.path` принимается только как внутренний путь, название выводится только как текст.
- Ошибка записи не теряет отметку: она действует, пока открыта страница, и рядом появляется сообщение.
- Другая вкладка подхватывает изменения. При одновременной правке побеждает последняя запись.
- Дат и серий дней здесь нет намеренно: курс без стриков и наказаний.

## `family100:notes:v1`

```json
{
  "schemaVersion": 1,
  "fields": { "d1-task-circle": "Текст записи", "d1-task-hard": "Текст личной записи" },
  "keep": ["d1-task-hard"]
}
```

| Поле | Что это |
| --- | --- |
| `schemaVersion` | Версия формата |
| `fields` | Постоянный id поля задания → текст записи. Пустых записей нет. До 10 000 знаков на запись |
| `keep` | Поля с `sensitive: true`, для которых сохранение включено явно |

Правила:

- Текст поля с `sensitive: true` сохраняется, только если его id есть в `keep`. Выключение сохранения сразу стирает текст из хранилища.
- Записи с неизвестным id не удаляются: они могут принадлежать дню, которого нет в этой сборке.
- Другая вкладка подхватывает изменения, но не трогает поле в фокусе и несохраняемый ввод.

## Файл копии

Копия — файл JSON `family-100-kopiya-ГГГГ-ММ-ДД.json`, его хранит сам пользователь. Записи в нём лежат открытым текстом.

```json
{
  "format": "family100-backup",
  "version": 1,
  "exportedAt": "2026-10-31T12:00:00.000Z",
  "progress": { "schemaVersion": 1, "checked": [] },
  "notes": { "schemaVersion": 1, "fields": {}, "keep": [] }
}
```

- Файл недоверенный: `progress` и `notes` проходят те же проверки, что и хранилище, а вывод на страницу идёт только через `textContent`. Предел размера — 1 МБ.
- Импорт заменяет данные, а не объединяет их, и только после предпросмотра и подтверждения. Текст чувствительных полей без `keep` при импорте отбрасывается.
- Файл новой версии не читается как старый: показываем сообщение, данные не меняем.
- «Стереть всё» удаляет `family100:progress:v1` и `family100:notes:v1` и очищает поля на странице.
